# 魅せるプレイ動画の依頼

PAPA ZERO を、オープニングからエンディング(エンドロールまで)を一度も飛ばさずに通した「魅せる」プレイ動画にしてほしい。
YouTube(<https://www.youtube.com/@suzuki-black-o4h>)に、トレーラー(<https://www.youtube.com/watch?v=BOctMxKXW5U>)の次の動画として上げる。

## 1. 作るもの

- **通しのプレイ動画(MP4)**: タイトル → オープニング(全部) → 1〜7 面 → 面の間の映像(全部) → エンディング → エンドロール。
- **魅せる自動プレイ**: 動画はこれで撮る。人が遊んだように見えて、しかも上手いプレイにする(2 章)。
- **YouTube の説明欄に貼るチャプター表**(面・映像ごとの開始時刻)。

## 2. 今の自動プレイが「瞬殺」になる理由

`src/engine/game_ai.c` の `auto_input()` は、

1. 当たり矩形(`hits`)のうち一番手前の敵を選び、
2. 照準(`aim_x`・`aim_y`)をその真ん中へ**その枚のうちに書き換え**(瞬間移動)、
3. すぐにバルカン(`IN_A`)を撃ち、ロックがあれば誘導弾も撃つ。

`aim_poll()` は `g_auto` のとき何もしないので、照準は人の速さ(`aim_step()`: 1 ティックに 2→4→6 ドット)で動かない。
そのため、敵は画面に出た枚に倒され、隊列も攻撃も見えない。試験(`test_flow.tcl`)で面を速く通すには良いが、動画には向かない。

## 3. 魅せる自動プレイの決まり

`g_auto = 3`(SHOW)として足す。`g_auto = 1`(試験)と `2`(タイトルのデモ)の動きは変えない。
3 はデモのように 40 秒で終わらず、最後まで遊ぶ。入れ方はタイトルの隠しコンフィグに足さず、録画のスクリプトがメモリへ書くだけでよい(容量を使わないため)。

### 3.1 照準を人の手で動かす

- `auto_input()` は照準を書き換えず、狙う所への**上下左右のビット**を返し、`aim_step()` に動かさせる(押し続けると速くなる、人と同じ加速)。
- 近くまで来たら速さを落として止める(行き過ぎて戻る小さな揺れは少しあってよい)。
- 狙う相手を替えるときは、照準が画面を流れていくのが見えるのが良い。

### 3.2 泳がせてから倒す

- 敵が画面に出ても、すぐには撃たない。隊列・動き方・名前の札(AI 認識の札)が読めるくらい見せてから倒す。目安は 1〜2 秒、または一定の距離まで近づいてから。
- 種類ごとの見せ場を残す: 並走する敵(`P_PARALLEL`)は横に振れるのを見せる、横切る敵(`P_CROSS`)は横切るのを少し見せる、など。
- ただし通り過ぎて逃がすことはしない(撃ち漏らしは少なく)。

### 3.3 敵弾をぎりぎりで撃ち落とす

- 敵弾(`T_FLAK`・`T_MISSILE`)は撃ち落とせる。残りティック(`tm`)が少なくなった、画面の手前まで来た弾を、ほかより優先して撃ち落とす。
- 「当たる直前に撃ち落とす」のを見せ場にする。ただし間に合わないほど待たない。

### 3.4 レーザーは撃たれる直前に止める

- 溜めている間(`laser[].st == 0`)に持ち主を倒せば止まる(`g_score += 30`)。溜めの点滅を少し見せて、発射の直前に持ち主を倒す。
- 止められないレーザー(`ldef` の `mhp` が 99)は、`ROLL!` で避ける。

### 3.5 誘導弾の一斉発射

- 敵が何体も出る所では、照準をゆっくり掃いてロックの枠に何体も入れ(最大 8 体、`lock_n`)、溜めてから続けて撃つ(ロックした敵へ順に飛ぶ)。
- 1 体ずつ撃つより、何本もの誘導弾が一度に飛ぶ絵を作る。

### 3.6 機動の指示

- `ROLL!`・`LOOP!`・`DIVE!` には応える。今の「受付の残りが少なくなってから押す」(`pr_t < 20`)のままでよい(ぎりぎりで避ける絵になる)。
- `LOOP!` で後ろの敵を前へ回したら、その敵を倒すところまで見せる。

### 3.7 バルカンの熱

- 過熱(`over_t`)で止まると格好が悪いので、熱(`heat_t`)が上がりきる前に指を離す。撃つのは「撃てば当たる」とき(照準が赤い)だけにする。

### 3.8 ボス

- `WARNING!` と登場(`boss_intro`)の間は撃たない。ボスの姿を見せる。
- 秘密兵器は予告を見せ、撃たせてから迎え撃つ(撃ち落とす・避ける)。部位は組(`boss_grp`)の順に、弱点を狙って落とす。
- 7 面のボス(すべての秘密兵器を順に使う)は一番の見せ場。ヒナのカプセル(`OF_CAPSULE`)は撃たない(今のコードと同じ)。

### 3.9 補給と被弾

- 補給の気球(AMMO・MED)を取るところも少し入れてよい。
- **動画では被弾しない**のが目標。安全のため無敵(`g_cfg.god`)を入れてよいが、被弾した回数は数えてログに出し、0 になるよう動きを直す(無敵だと `damage()` が先に返り、画面には出ないため、数えるなら `damage()` の入口で)。

### 3.10 残り時間とエンディング

- エンディングの父と娘の会話は、残り時間(`g_clock`)が 1:00 以上か(`g_clock >= 0x10`)で変わる(`op.c`)。ミスせずに通すと 7 面のボスで約 2:00 残る(`TODO.md`)。
- 泳がせる分だけ時間が延びるので、**1:00 以上残る**ように見せ方の長さを調整する(良いほうのエンディングを撮る)。

### 3.11 置き場所

- ページ 0 にも `HICODE`(0xA300-、`game_ai.c`)にも空きがほとんど無い。足すコードの置き場は、空きのある所(面のコード `stg.c` の置き場など)へ移すか、今の `auto_input()` を詰めて作る。`mkrom.py` の重なりの検査を通すこと。
- タイトルのデモ(`g_auto = 2`)と試験(`g_auto = 1`)が今までどおり動くことを確かめる。

## 4. 録画

### 4.1 機械

- openMSX、`Panasonic_FS-A1ST`(作者の吸い出した turboR の ROM で組んだ機械)。`-carta build/PapaZero.rom -romtype ASCII8`。

### 4.2 スクリプト

`tools/test_flow.tcl` をもとに `tools/record_flow.tcl` を作る。

- タイトルを数秒見せてから Space で始める。**オープニングは飛ばさない**(オープニングの間に Space を押すと飛ぶので、始めた後は Space を押さない)。
- 始めたら `g_auto` に 3 を書く(試験と同じく、毎回書き直してよい)。
- 録画は openMSX の `record start`(映像と音が一緒の AVI、`~/.openMSX/videos/` に出る)。エンドロールが終わったら `record stop` して終える。
- `throttle off` のままでも録画は 1 枚ずつ取られるので、速く回してよい(音も揃う)。
- 状態(面・残り時間・被弾の回数・スコア)をログに出し、チャプター表を作るため、**面と映像が切り替わった時刻(動画の頭からの時間)**も出す。

### 4.3 MP4 へ

- ffmpeg で H.264 + AAC の MP4 にする。ドットの絵がにじまないよう、拡大は**最近傍**(`flags=neighbor`)で整数倍にし、1920×1080 に収める(余りは黒の帯)。
- フレームレートは openMSX の出力のまま(60 fps)。

## 5. 確かめること

- [ ] オープニング、6 つの面の間の映像、エンディング、エンドロールが全部入っている(飛ばしていない)。
- [ ] 敵が出た枚に倒されていない。照準が瞬間移動していない。
- [ ] 敵弾の撃ち落とし、レーザーを止める所、誘導弾の一斉発射、ROLL・LOOP が何度か入っている。
- [ ] 被弾 0(ログで確かめる)。過熱で止まっていない。
- [ ] 残り時間 1:00 以上でエンディングに入っている。
- [ ] 音と絵がずれていない(映像の場面は曲に合わせて作ってある)。
- [ ] 動画を何か所か見て、変な動き(照準が細かく震える、同じ敵の前で止まる など)が無い。
- [ ] タイトルのデモと `test_flow.tcl` の自動プレイが今までどおり動く。
