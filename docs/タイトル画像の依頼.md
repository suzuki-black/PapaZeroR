# タイトル画像の依頼(PAPA ZERO)

タイトル画面の絵を描いてもらうための要望。2026-11-09 にこの依頼で Microsoft Copilot に描いてもらった絵を `data/title_art.webp` に入れた
(前の仮の絵は図形を並べて描いたもので、外した)。文字は絵に入れず、書体 Anton で別に描いて重ねる(`tools/gen_title_text.py`)。

## どんなゲームか

- MSX turbo R 用のコクピット視点の 3D シューター。仮題は **PAPA ZERO**。
- 筋: 農場の静かな朝、父が少し目を離した隙に、近くの町を制圧したテロ集団が戦闘機で家の前に降り、2 人組が娘の **ヒナ** をさらう。
  6 時間後、ヒナはロケットで宇宙へ運ばれる。父は警察を呼ばず、納屋に置いてあった **魔改造の零戦** で追う。
  町 → 港 → 谷 → 雲海 → 成層圏 → 宇宙(鍵穴の形の基地)と追いかけ、取り戻す。
- 雰囲気: 80 年代のアクション映画のような、娘を取り戻しに一人で向かう父の話。重すぎず、熱く。
  ただし特定の映画のポスターや場面をなぞらない。

## 絵に入れてほしいもの(優先順)

1. **魔改造の零戦**(主役の機体)。零式艦上戦闘機(A6M)の形がはっきりわかること。
   - 色はゲームの中と合わせたい: 上面は明るい灰色(初期型の飴色がかった明灰白色)、エンジンのカウリングは黒、主翼と胴に日の丸。
   - 「魔改造」は控えめでよい(翼の下の誘導弾、機首の小さなセンサーなど)。零戦に見えることを優先。
2. **父**。顔ははっきり描かなくてよい(後ろ姿、操縦席の中の背中、横顔の影など)。中年で、元パイロットの気配。
3. **ヒナ**(娘)。8 歳くらい、**赤い服とおさげ**(ゲームの中の絵と同じ)。
   入れるなら「遠くの空のカプセルの中」「父の手にある写真」など、さらわれていることがわかる形で。無理に入れなくてよい。
4. 背景: **朝焼け**(紫 → 橙 → 黄の空)と、**赤い納屋**(零戦が置いてあった所)。遠くに煙の上がる町や、空へ昇るロケットがあってもよい。

## 文字は描かないでください

タイトルの文字はゲームのほうで重ねる。絵には文字・ロゴ・署名・透かしを入れない。
重ねる文字と位置(画面 256 × 212 の行。割合は縦の位置):

| 文字 | 行 | 縦の位置 | 横幅 |
|---|---|---|---|
| PAPA ZERO(金から赤茶の Anton。1 行) | 4〜44 | 上から 2〜21% | 中央の 76% ほど |
| PUSH SPACE KEY(白。点滅) | 164〜179 | 77〜84% | 中央の 50% ほど |
| © 2026 suzuki-black | 193〜207 | 91〜98% | 中央の 50% ほど |

(依頼したときは PAPA と ZERO を 2 行のブロック文字で重ねる予定だったが、絵を受け取ってから 1 行の Anton に替えた)

- **PAPA と ZERO の間(縦の 19〜39%)** は文字が無いので、いちばん見せたいもの(零戦の機首、父の背中など)をここに置いてほしい。
- 文字の左右(中央の 41% の外)も見える。文字の帯の真ん中に大事なものを置かない。

## 技術の制約(MSX の画面に変換するので)

- 最終的に **256 × 212 ドット**に縮め、**SCREEN 11(YJK)** で表示する。
  - 明るさは 1 ドットごとに 16 段階、**色は横 4 ドットで 1 つを共有**する。横に細かく色が変わる所(細い線、小さな模様)はにじむ。
  - 大きな形・はっきりした明暗・なめらかなグラデーションは向いている。細い線や小さな文字は消える。
- **縦横比 4:3** で納品してほしい(800 × 600 以上。1024 × 768 くらいが扱いやすい)。中央を 4:3 で切り出して縮める。
- 形式は PNG(RGB)。背景を透明にしない。

## 権利まわり

  そのように公開・再配布してよいかを確かめてほしい。

- 零戦・日の丸は実在の機体と記章を借りるだけ(README の免責に書いてある)。
- クレジットの書き方(例:「Title illustration: ○○ × Claude Code」)を決めたい。

## 受け取った後の手順

```bash
cp <受け取った絵> data/title_art.webp            # 形式は Pillow で読めればよい(Makefile の名前に合わせる)
python3 tools/gen_title.py data/title_art.webp /tmp/t.bin /tmp/t.h /tmp/title_preview.png   # MSX での見え方を確かめる
make
```

`/tmp/title_preview.png` が、実機と同じ式で色を戻した見え方になる。文字との重なりもここで確かめる。
